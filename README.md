# Python Basics – Task 1

A beginner Python script covering the fundamentals:

- Data types and `type()`
- String concatenation
- User input and calculating sum / average
- f-string formatting
- Arithmetic and logical operators
- String methods
- Lists (indexing, slicing, modification)

## Run

```bash
python task_1.py
```

Requires Python 3.6+ (for f-strings). The script will ask for two numbers.
